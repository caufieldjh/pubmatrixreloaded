Before you start

Where the data comes from
A copy of PubTator3's bulk annotations, release , kept on Hugging Face. It is not the live PubTator3 service and it is not updated automatically, so counts differ from PubTator3's own by a few percent, and from PubMed's by much more. PubTator3 covers PubMed abstracts and PMC full text.
What can be searched
Genes, diseases, and chemicals, by name. Assays, methods, and other phrases cannot be searched here: they have no bulk data. The command line tool can search them.
Where it runs
In this browser tab, on your computer. There is no server of ours and nothing is kept. Your browser fetches its search engine from jsDelivr and duckdb.org and the data from Hugging Face. Hugging Face can see which pieces of the data are read, which reveals roughly what you searched.

How your terms were read

These readings come from text mining and can be wrong: apoptosis reads as a disease, for example, because that is how it was tagged. Follow a link if you are unsure of an entity.

Keep this tab open until it finishes. Closing or reloading it loses the search, because nothing is saved until you download the results. You can use other tabs and windows meanwhile, though browsers may slow a tab you are not looking at. Your computer must stay awake and online.

Or run the command line tool, for phrases, the live PubTator3 service, and Excel files

The tool searches PubTator3 itself, so it can use any phrase and has the newest data. It is limited to about two requests a second, so large searches take hours. It uses the same lists as above.
