PubMatrix Reloaded

Count the literature for every pair of terms from two lists, using PubTator3. A rebuild of PubMatrix.

This page does not run searches. PubTator3 does not accept requests from web pages, so searches run on your computer: plan one here, run the command, then bring the results back to view.
