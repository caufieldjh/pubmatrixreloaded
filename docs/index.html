Set "Look up as" for a list of one kind. A chemical list needs it: PFOA is also the gene pfoA. A list of assays or methods needs "phrases only": otherwise LLNA reads as a disease.

Europe PMC matches a phrase's exact words, while PubTator3 also matches variants such as plurals. List the variants you mean: chromosomal aberration | chromosomal aberrations.

Before you start

Where the data comes from
Genes, diseases, and chemicals: a copy of PubTator3's bulk annotations, release , kept on Hugging Face. It is not the live PubTator3 service and it is not updated automatically. Phrases, such as assays and methods: Europe PMC, live. Both cover abstracts and open full text, but they are different sources, so a cell that uses a phrase is an estimate. Entity counts differ from PubTator3's own by a few percent. In one test of toxicity assays, phrase counts had a median within 1% of PubTator3's, but single phrases ranged from less than half to a quarter more, mostly because of exact wording. Counts from PubMed differ much more.
What can be searched
Any named gene, disease, or chemical, and phrases of up to 100,000 documents. Relation counts need entities on both sides. The command line tool has no such limits.
Where it runs
In this browser tab, on your computer. There is no server of ours and nothing is kept. Your browser fetches its search engine from jsDelivr and duckdb.org, data from Hugging Face, and phrases from Europe PMC. Europe PMC sees your phrases, and Hugging Face can see which pieces of the data are read, which reveals roughly what you searched.

How your terms were read

These readings come from text mining and can be wrong: apoptosis reads as a disease, for example, because that is how it was tagged. Follow a link if you are unsure of an entity.

Keep this tab open until it finishes. Closing or reloading it loses the search, because nothing is saved until you download the results. You can use other tabs and windows meanwhile, though browsers may slow a tab you are not looking at. Your computer must stay awake and online.

Searching

Keep this tab open. Stopping keeps what is finished so far. Phrases are fetched first and a cell needs its whole phrase, so stopping during that part keeps nothing.

Or run the command line tool, for the live PubTator3 service, very common phrases, and Excel files

The tool searches PubTator3 itself, so it uses one source for everything and has the newest data. It is limited to about two requests a second, so large searches take hours. It uses the same lists as above.
